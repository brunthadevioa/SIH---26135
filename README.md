# MahaSkill 360

Empowering Maharashtra's Skilling Ecosystem with AI-driven analytics, fraud detection, candidate provenance, and direct benefit monitoring.

---

## 🚀 Quick Setup Instructions (How to run on your laptop)

### Prerequisites
1. **Node.js** (v18 or higher): [Download & Install Node.js](https://nodejs.org/)

---

### Steps to Run

1. **Extract/Unzip** the project folder.
2. **Open Terminal / Command Prompt** in the unzipped folder:
   - On Windows: Open the project folder, click on the folder path bar at top, type `cmd` or `powershell`, and press Enter.
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Start the Application**:
   ```bash
   npm run dev
   ```
5. **Open in Browser**:
   - Web App UI: [http://localhost:3000](http://localhost:3000)
   - Backend API: [http://localhost:5000](http://localhost:5000)

---

### Project Structure
- `src/` — React frontend application with Tailwind CSS, Lucide icons, and Recharts.
- `server/` — Express backend API with dynamic mock data engines and endpoints.
- `package.json` — Scripts and dependencies configuration.
